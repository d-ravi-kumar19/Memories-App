Welcome to the Memory API

Welcome to the Memory API documentation. This API provides functionalities for managing posts in the Memory application, including creating, retrieving, updating, and deleting posts, as well as user authentication and interaction features.

Swagger Documentation

For detailed information about the API endpoints and to interact with them, visit the Swagger UI.

Project Overview

The Memory API is designed to handle various operations for the Memory application, such as:

  • Managing posts including creation, updates, and deletions.
  • Handling user authentication and authorization.
  • Enabling post interactions such as liking and commenting.

Swagger UI provides a user-friendly interface to explore the API's capabilities and test its endpoints directly from your browser.
